O que é um Projeto de Software?
R: Um projeto de software consiste no planejamento e na criação de um sistema para resolver um problema ou suprir uma demanda. Ele abrange fases como análise de requisitos, planejamento, programação e testes. Ao longo do projeto, estabelecem-se as funcionalidades, tecnologias e recursos indispensáveis. O objetivo é desenvolver um software que seja funcional, eficiente e atenda às demandas dos usuários.



O que difere um "Projeto de Software" de um "Script/Código
isolado"?
R:Um projeto de software abrange planejamento, definição de requisitos, desenvolvimento, testes e manutenção.
Por outro lado, um script ou código isolado costuma executar uma tarefa específica de maneira simples e direta.




Ciclo de Vida Básico:
Levantamento de Requisitos / Escopo: Estabelece as funcionalidades do sistema e seus limites.

Desenvolvimento / Codificação: fase em que o sistema é programado conforme as especificações estabelecidas.

Testes / Qualidade: Avalia se o sistema opera de maneira adequada e identifica possíveis falhas.

Entrega / Implantação: O sistema é disponibilizado para uso e instalado no local do cliente.



Alinhamento com a Nova Web Studio:
Estabelecer um escopo fechado previne alterações e novas demandas ao longo do desenvolvimento.
Isso possibilita uma melhor organização do tempo, dos recursos e das atividades do grupo.

Etapa 2 - Avaliação do Projeto

1. Identificação de plataformas
O sistema é compatível com computadores, tablets e aparelhos móveis. No desktop, há mais espaço para dados. Para facilitar o toque em tablets e celulares, os componentes precisam ser maiores e a interface mais simplificada.

2. Potencial da Plataforma Computacional
A interface precisa ajustar-se ao tamanho da tela. Telas maiores têm a capacidade de exibir mais informações, ao passo que telas menores requerem menos elementos. A utilização e a leitura são facilitadas por botões maiores e tabelas organizadas.

3. Fundamentos do Projeto de Software
O projeto no Figma obedece aos princípios de usabilidade, consistência e estruturação. Os botões, textos e cores seguem um padrão, ao passo que as telas são organizadas por funções, o que simplifica a utilização e a futura implementação do sistema.


Aula 08 pesquisa

Projeto Nova-Web - Diretrizes de UI/UX (Página de Login)

1. Princípios de usabilidade em formulários 

Etiquetas vs. Marcadores de posição

O campo é permanentemente identificado pelo label, ao passo que o placeholder atua apenas como exemplo ou guia. Portanto, o placeholder não deve ser usado como substituto do label, já que pode sumir quando o usuário inicia a digitação.

Hierarquia de Visibilidade

O Primary Button, como "Entrar", deve receber maior ênfase visual, pois representa a ação principal. Ações secundárias, como "Criar Conta" e "Esqueci a Senha", devem receber menos destaque.

2. Situações de Validação dos Campos (Input States)

Padrão: borda neutra e rótulo legível.

Focus (Foco): realce na borda ou contorno quando o campo está selecionado.

Error (Erro): borda vermelha e mensagem explicativa abaixo do campo.

Success (Sucesso): sinal visual indicando que o preenchimento está correto.

Disabled (Desabilitado): visual com contraste diminuído para sinalizar que o campo não está disponível.

3. Normas de Acessibilidade

Empregar um contraste apropriado entre textos e fundos, de acordo com as diretrizes da WCAG.

Assegurar um feedback claro para os leitores de tela.

Habilitar a navegação pelos campos com a tecla Tab.


Pesquisa Aula 09

Projeto Nova-Web - UI/UX Design
Aula 09: UX de Tabelas de Dados e Telas de Perfil
1. Pesquisa Teórica - UX para Tabelas Corporativas
Alinhamento de Dados
Textos ficam alinhados à esquerda para facilitar a leitura.
Números e valores ficam alinhados à direita para facilitar a comparação.
Status e botões podem ficar centralizados.
Filtros e Busca
A barra de pesquisa deve ficar em um lugar fácil de encontrar, normalmente acima da tabela.
Os filtros ajudam a encontrar informações específicas.
A ordenação facilita a comparação dos dados.
Organização Visual
O cabeçalho fixo ajuda a identificar as colunas enquanto a pessoa rola a tabela.
Alternar a aparência das linhas facilita acompanhar os dados.
Espaçamentos e bordas leves deixam a tabela mais organizada.
Esses recursos ajudam o usuário a encontrar e entender as informações com mais facilidade.
Acessibilidade
É importante usar corretamente elementos como <th> e <td> nas tabelas.
Isso ajuda pessoas que utilizam leitores de tela a entender melhor os dados.
